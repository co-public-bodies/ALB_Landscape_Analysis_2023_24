<p>This app lets you explore data on the Arm's Length Body Landscape for the 2022-23 and 2023-24 Financial Years. This was collected by the Cabinet Office from departments across the UK Government, and is a continuation of the historic <a href='https://www.gov.uk/government/collections/public-bodies' target='_blank'>Public Bodies Directory publication</a>.</p>

<p>With this tool you can visualise data for ALBs within different departments, and can build tables with variables you are interested in. For detailed analysis of the Arm's Length Body Landscape, you can also visit our publications:
<ul><li><a href='https://co-public-bodies.github.io/ALB_Landscape_Analysis_2022_23/' target='_blank'>ALB Landscape Analysis for the 2022-23 Financial Year</a>.</li>
<li><a href='https://co-public-bodies.github.io/ALB_Landscape_Analysis_2023_24/' target='_blank'>ALB Landscape Analysis for the 2023-24 Financial Year</a>.</li></ul>
</p><p>The code for this app is available at <a href='https://github.com/co-public-bodies/ALB_Landscape_Analysis_2023_24/' target='_blank'>https://github.com/co-public-bodies/ALB_Landscape_Analysis_2023_24/</a>.</p>
<p><b>Note:</b> There are a few cases in this data where multiple ALBs are represented under the same name, to avoid double counting where they share the same resources. These are indicated by the number of bodies in brackets after the name. For example, 'ALB Name (x2)' represents two ALBs with the same name. In 2023/24 there were 304 ALBs, but due to multiple cases of ALBs sharing the same name, there are 251 unique rows represented in the dataset.</p>
